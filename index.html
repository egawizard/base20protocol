Why BASE-20
Three principles the protocol won't compromise on.
01 / NATIVE

Built on Base, not wrapped for it

No bridged supply, no synthetic wrapper. Every BASE-20 token is inscribed and settled directly in Base's own execution environment.

02 / FAIR

Community first, by design

No presale, no team allocation, no insider mint window. Genesis opens the same block for everyone watching.

03 / VERIFIABLE

Inscription-based, not off-chain

Supply, ticker, and mint state live onchain as inscriptions — readable, indexable, and provable without trusting a server.

A standard, not a token.

BASE-20 defines how fungible inscriptions are deployed, minted, and transferred on Base — the same way earlier inscription standards did for their own chains, adapted for Base's block times and fee environment.

  • Deploy — set ticker, max supply, mint limit
  • Mint — inscribe within limit until max supply is reached
  • Transfer — inscribe, then send the inscription onchain
